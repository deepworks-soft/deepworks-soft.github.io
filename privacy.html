Какие данные используются

Для входа Yo-ho получает идентификатор аккаунта и доступные данные профиля выбранного сервиса (Яндекс, Google, Telegram или VK ID), например имя и изображение профиля, а в случаях, когда сервис их предоставляет, адрес электронной почты. Пароль стороннего аккаунта вводится у самого сервиса. Для поддержания входа используются токены и сессии.

Для доступа в клуб обрабатываются идентификатор аккаунта, приглашение, статус доступа и идентификаторы устройств. Для персональных функций — профили, история, прогресс, избранное, оценки, списки, настройки и распознанные композиции.

Для общения используются никнейм, запросы, друзья, советы и активность, если пользователь разрешил её показ. Приложение может отправлять техническую статистику работы и сведения об ошибках, в том числе модель устройства и версию приложения. Отправка сообщения владельцу может включать диагностические сведения.

Где хранятся данные

Локальные настройки, кеш и личные данные хранятся на устройстве. Сервер Yo-ho на Cloudflare хранит данные аккаунта, клуба, синхронизации и социальных функций. При входе через Яндекс также может использоваться папка приложения на Яндекс Диске. Резервные копии сервера хранятся в закрытом доступе владельца.

Yo-ho не предназначен для хранения видеофайлов на сервере. При воспроизведении используются временные данные. Внешние источники и участники одноранговых сетей могут получать IP-адрес устройства или сетевого посредника и технические сведения, необходимые для передачи данных.

Сторонние сервисы

Выбранный сервис авторизации обрабатывает данные входа по своей политике. Для каталога и изображений могут использоваться Кинопоиск, TMDB и OMDb; для распознавания музыки — AudD, куда при использовании функции передаётся фрагмент звука. Cloudflare обеспечивает серверные функции. Telegram используется для входа и, отдельно, для подключаемых функций бота и канала.

Данные не продаются для рекламы. Друзья могут видеть активность в пределах выбранных настроек приватности.

Управление данными

В разделе «Профили и друзья» можно изменить настройки показа просмотров. Для смены аккаунта или выхода используйте экран аккаунта. Запросы на доступ к данным, их исправление или удаление направляйте владельцу через «Справка» → «Сообщить о проблеме». Удаление локальных данных не равнозначно удалению серверных данных. Резервные копии могут сохраняться до их планового удаления.
