Способ 1. Downloader

Рекомендуемый способ без компьютера. Названия меню могут различаться в зависимости от производителя и версии Android.

Код Downloader
9193785
Шаг 01

Откройте Google Play

На главном экране телевизора откройте магазин приложений. Найдите Downloader (обычно называется Downloader by AFTVnews) и установите его, если он доступен для вашей модели.

Шаг 02

Введите код или адрес

Запустите Downloader. В поле URL введите 9193785 либо полный официальный адрес https://deepworks-soft.github.io/tv/. Нажмите Go. Если код не открывается, используйте адрес.

Шаг 03

Загрузите APK

На странице для ТВ выберите «Скачать Yo-ho». Загружается стабильный универсальный APK из официального GitHub. Дождитесь окончания загрузки.

Шаг 04

Разрешите установку

Если Android блокирует установку, откройте предложенные системные настройки и включите разрешение «Установка неизвестных приложений» только для Downloader. На старых версиях Android настройка может называться «Неизвестные источники». Возвратитесь в Downloader. Не отключайте системную защиту целиком.

Шаг 05

Установите Yo-ho

Нажмите «Установить», дождитесь завершения, затем «Открыть». После установки можно убрать разрешение для Downloader и удалить скачанный APK из папки загрузок.

Способ 2. Флешка или файловый менеджер

  1. С компьютера или телефона откройте официальный стабильный релиз и скачайте файл Yo-ho-<версия>.apk. Не берите архив исходников.
  2. Скопируйте APK на USB-накопитель и подключите к телевизору. Если USB недоступен, перенесите файл доверенным способом передачи файлов по локальной сети.
  3. Откройте APK в файловом менеджере ТВ, при необходимости разрешите установку неизвестных приложений для этого менеджера.
  4. Нажмите «Установить», затем «Открыть». Не используйте модифицированные APK из сторонних источников.

Первый вход и приглашение

  1. Откройте Yo-ho и выберите один из доступных способов входа: Яндекс, Google, Telegram или VK ID. Список зависит от настроек клуба.
  2. Наведите камеру телефона на QR-код на телевизоре и перейдите по ссылке. Завершите вход у выбранного сервиса. Для Яндекса также доступен код на ya.ru/device.
  3. Дождитесь подтверждения входа на телевизоре. При первом входе введите личный код приглашения, полученный от владельца. Не публикуйте QR-код или приглашение.
  4. Укажите никнейм, если приложение предлагает это сделать. После подтверждения доступа откроется основное меню.
Если вы уже участник клуба, используйте прежний способ входа и тот же аккаунт. Другой способ входа может создать отдельный аккаунт, для которого потребуется новое приглашение.

Если Yo-ho уже установлен

  1. Откройте Настройки → Информация → Проверить обновления.
  2. Выберите предложенное стабильное обновление и дождитесь загрузки.
  3. Подтвердите установку системным установщиком. При запросе разрешите установку для Yo-ho.
  4. Откройте приложение. Не удаляйте старую версию и не очищайте данные: установка поверх помогает сохранить настройки и историю.

Если что-то не получается

Downloader отсутствует в магазине

Попробуйте способ установки через USB или доверенный файловый менеджер. На телевизорах без Android TV APK не устанавливается.

Скачивание не начинается

Проверьте подключение к интернету. Введите полный адрес TV-страницы вместо короткого кода. При недоступности GitHub попробуйте позже.

Установка заблокирована

Проверьте разрешение на установку для приложения, которым открываете APK, и свободное место. Названия системных настроек отличаются.

Приложение не установлено или ошибка пакета

Проверьте, что скачан именно официальный APK, он полностью загрузился и устройство совместимо. Не удаляйте рабочую версию без необходимости — обратитесь к владельцу.

Нет доступа после входа

Проверьте правильность приглашения и способ входа. Если аккаунт ранее был допущен, используйте тот же способ авторизации. Обратитесь к владельцу клуба.

Телевизор медленно работает

В Yo-ho можно включить облегчённый режим в настройках. Для видео используйте доступное качество, которое поддерживает устройство и сеть.
